== Description ==

Visual Site Studio is a commercial-grade WordPress toolkit for agencies and site owners:

* Visual front-end editor with a real design panel (not browser prompts)
* Persistent CSS with unique selectors, page or site scope, undo/redo
* White-label admin bar + custom dashboard widgets
* Scheduled, audience-aware content snippets and a Gutenberg block
* JSON export/import for agency presets

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate Visual Site Studio
3. Open **Site Studio** in wp-admin, then visit the front end and click **Studio**
